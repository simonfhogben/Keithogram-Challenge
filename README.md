# The Keithogram Challenge

A free, static GitHub Pages site containing 30 British cryptic-style Keithograms, each with ten main clues and Admiral Keith's three-clue maritime bonus round.

## Included features

- 30 puzzles: Gentle 1-10, Proper 11-20, Savage 21-30
- Answers and clue explanations
- Local player names, scores, league table and recent activity
- Admiralty Board and maritime titles
- Dark/light themes, A+/A- controls and Tea-Time Mode
- Optional shared Google Sheets scoreboard
- No account, password or email collection

Start with `SETUP-GUIDE.md` for deployment.
